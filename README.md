# 光学就业网 · 光学工程师招聘

> 全国光学工程师招聘信息汇总 —— 单文件网页版，浏览器打开即用。

**👉 在线访问：<https://alice-p197.github.io/optical-engineer-jobs/>**

## 项目简介

「光学就业网」是一款面向光学工程师求职者的招聘信息汇总页面，集中展示全国范围内的光学相关岗位招聘信息。

- 单文件网页应用，无需安装，打开即用
- 内嵌字体（Inter），自包含样式，离线也可正常展示
- 页面为静态 HTML，可直接部署到任意静态托管

## 使用方式

- **在线浏览**：访问上方 GitHub Pages 链接
- **本地查看**：直接用浏览器打开 [`optical-engineer-jobs.html`](./optical-engineer-jobs.html)
- **部署**：克隆本仓库（或下载 HTML 文件）后放到任意静态服务器 / 托管服务即可

## 仓库文件说明

| 文件 | 说明 |
| --- | --- |
| `optical-engineer-jobs.html` | 招聘信息主页面（单文件网页应用） |
| `index.html` | 入口跳转页，自动重定向到主页面 |

## 技术说明

- 静态 HTML + 内联 CSS，页面自包含（含 base64 内嵌字体）
- 无第三方运行时依赖，部署后无需联网加载脚本
